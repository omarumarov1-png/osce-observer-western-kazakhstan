# OSCE Observer — Western Kazakhstan

Interactive map of polling station (UIK) locations across Aktobe and West Kazakhstan oblasts — built to support election observation fieldwork.

**[Open the live map →](https://omarumarov1-png.github.io/osce-observer-western-kazakhstan/)**

## What's in it

491 polling stations across 9 regions:

**Aktobe oblast** — Aktobe city, Khromtau, Martuk, Kobda, Karagaly (Badamsha), Alga & Mugalzhar (Kandyagash) districts
**West Kazakhstan oblast** — Uralsk city, Akzhaiyk district (Chapaev), Burli district (Aksai)

Each polling station shows its official address, the building/institution it's housed in, and its administrative group (raion/city district or rural okrug), plotted on an interactive Leaflet map with search, filtering, and clustering.

## Data provenance and accuracy

Source addresses come from official akimat (local government) decrees listing polling station boundaries, provided as Word documents. Coordinates were then generated by:

1. Geocoding each address against [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/), constrained to each region's bounding box to reject cross-region name collisions.
2. Cross-checking against [2GIS](https://2gis.kz/) where coverage allowed (dense in Aktobe and Uralsk cities; sparse to absent in small rural villages), preferring direct institution-name matches over generic street-level hits.
3. Manually reviewing any correction that would have overridden an already-confident match, to catch cases where a second source pointed at a different department of the same institution rather than a genuine fix.

Every polling station is tagged with a confidence level:

- **High** — verified against a specific building or a direct institution-name match from a second independent source.
- **Medium** — a real address match, but not independently cross-checked; marked "unverified address" in the UI.
- **Low** — no reliable geocoding match was found; placed at a village or district centroid as a rough estimate, marked "≈ approximate" and flagged in both the sidebar and the map popup.

Rural districts generally have lower precision than the two city maps (Aktobe, Uralsk), since OpenStreetMap and 2GIS both have much sparser coverage of small villages than of city streets. Any pin marked medium or low confidence should be verified on the ground before being relied on for fieldwork.

## Running locally

No build step — static files only.

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Structure

```
index.html          — app shell (landing page + map view, hash-routed)
assets/app.css       — styles
assets/app.js        — router + Leaflet map rendering, data-driven per region
data/manifest.json   — region metadata (title, oblast, counts, map bounds)
data/<region>.json   — per-region polling station data
```
